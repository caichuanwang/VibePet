## 1. 目标与范围

把 VibePet 的宠物资源模型从"照片抠图的单张 PNG + 程序化动画"**整体替换**为 **Codex 开放宠物格式（spritesheet）**，并新增精灵动画渲染器，使宠物用 9 行精灵表达 agent 活动状态。

> **锚定原则（平台中立）**：VibePet 兼容的是**标准 Codex 宠物格式**与 **`~/.codex/pets/` 这个标准位置**，**不绑定任何单一画廊平台**。petdex.dev / codex-pet.com 等只是产出该格式的来源举例；任何把宠物装进 `~/.codex/pets/` 的方式都受支持。

### 成功标准（可验证）
1. VibePet 能加载并渲染合法的 Codex 宠物（`pet.json` + spritesheet，8×9 网格、192×208 单元格），按当前宠物状态播放对应行、循环帧。
2. 宠物列表聚合三类来源并按 slug 去重：**共享 `~/.codex/pets/`（原地引用、实时同步）** + **VibePet 导入目录（拖拽导入）**；**本版不含自带宠物**。
3. 宠物状态行由子项目 1 的 `SessionState` 派生驱动：idle / running / review / waving / failed。
4. **空状态**：无任何可用宠物时（既没装 Codex 宠物、也没导入），显示可读引导而非空白/崩溃。
5. 透明区域鼠标穿透改为吃"当前帧 alpha"，仅本体响应拖动/点击。
6. 抠图管线代码按存档后删除，`swift build` / `swift test` 通过，无悬挂引用。

### 非目标
- App 内画廊浏览/一键安装（`npx petdex install`）——留待后续，**本版不引入网络**。
- 自带默认宠物（已决定不做）。
- 老用户迁移（现无用户，直接丢弃，见 §7）。
- 会话模型、hook 覆盖（子项目 1）；终端跳回（子项目 3）。

## 2. 宠物资源模型（Codex 格式）

`PetAsset` 从"单 PNG（UUID 文件夹）"改为"**Codex 宠物文件夹引用**"。新形态（草案，字段名以 inspect 真实 `~/.codex/pets/boba/pet.json` 为准）：

```
struct PetAsset {
    let slug: String                  // = 文件夹名，对齐 Codex 生态、用于去重
    let displayName: String
    let source: PetSource             // .codexShared / .imported
    let folderURL: URL
    let spritesheetURL: URL
    let grid: SpriteGrid              // cols/rows/cellW/cellH（缺省 8×9×192×208）
    let stateRows: [PetVisualState: Int]?  // pet.json 声明的状态→行映射；nil → canonical 兜底
    let frameCounts: [Int]?           // 每行帧数；nil → 缺省 6
    let loopMs: Int                   // 缺省 1100
}

enum PetSource { case codexShared, imported }
```

- 标识用 **slug**（不再用 UUID）。
- `~/.codex/pets/` 原地引用、不拷贝（用户在 Codex 新装宠物，VibePet 立即可选）。

## 3. 宠物来源聚合

`PetAssetStore` 改为**多根聚合读取器**：

| 来源 | 位置 | 读写 |
|---|---|---|
| 共享 Codex 宠物 | `~/.codex/pets/<slug>/` | 只读、原地引用 |
| VibePet 导入 | `~/Library/Application Support/VibePet/pets/<slug>/` | 拖拽导入时拷入 |

- `list()`：扫两个根目录 → 解析各 `pet.json` → 校验 → 按 slug 去重（**导入目录优先**）→ 返回 `[PetAsset]`。
- 共享目录可能不存在（用户没装 Codex）→ 返回空，不报错。
- 校验失败的宠物（缺文件/网格尺寸不符）跳过并记录可读原因，不影响其它宠物。

---

## 4. 精灵渲染

**`SpriteSheetAnimator`**（替换程序化 `PetAnimations` 驱动）：
- 加载 spritesheet → 按 `grid` 切片为 cols×rows 帧。
- 按当前 `PetVisualState` 选定**行号**（`stateRows` 声明优先；缺失走 canonical 顺序），循环播放该行帧：缺省 6 帧、`loopMs` 周期，**尾部全透明帧跳过**。
- 渲染：`CGImage` 逐帧裁剪 + SwiftUI `TimelineView` 步进；按目标高度（沿用 `PetView.spriteSide` 量级）等比缩放、高质量插值。
- **Reduce Motion**：降级为该状态行第 0 帧静帧（沿用现有无障碍逻辑）。
- **命中穿透**：复用 `SpriteHitMask` 思路，改为对"**当前帧** alpha"建掩码（帧切换时更新），保持透明穿透、仅本体响应。

## 5. 状态 → 动画行映射

数据流：子项目 1 `SessionState` → 聚合派生 `PetVisualState` → 行号。

```
enum PetVisualState { case idle, running, review, waving, failed }
```

| `PetVisualState` | 由 `SessionState` 聚合派生 | canonical 行（pet.json 未声明时） |
|---|---|---|
| `review` | 存在 `requiresAttention` 会话（waitingForApproval/Answer） | review |
| `running` | 否则存在 running 会话 | running |
| `waving` | sessionStarted 打招呼 / 干净 completed（短暂） | waving |
| `failed` | StopFailure / 错误 completed（短暂） | failed |
| `idle` | 无活跃会话 | idle |

- 优先级：`review > running > waving/failed(瞬时) > idle`。
- `stateRows` 以 `pet.json` 声明为准；声明缺失用 canonical 顺序（idle/running/review/waving/failed/…）兜底。不同画廊宠物行序差异由此吸收。

## 6. UX 改动

- **Onboarding 第 ② 步**："生成宠物"→"**挑一个宠物**"：列出聚合宠物供选；**无宠物时**显示空状态引导（见 §6.1）。
- **设置页 / 菜单栏**："切换宠物"改为从聚合列表选择；提供"导入宠物文件夹…"（拖拽或选取）。
- **拖拽导入**：接受含 `pet.json` + spritesheet 的文件夹，校验后拷入 VibePet 导入目录；复用存档中导入状态机的"拖入 → 校验 → 落地"流程划分（§存档 2.4）。

### 6.1 空状态（关键）
本版不含自带宠物，故首启/无宠物时必须有可读引导，而非空白：
- **平台中立**：VibePet 锚定的是**标准 Codex 宠物格式 + `~/.codex/pets/` 位置**，不绑定任何单一画廊。文案不点名某个平台为"唯一方式"。
- 引导两条路：① **用任意方式获得一个 Codex 宠物**——任意画廊（petdex.dev、codex-pet.com 等，仅作举例）、Codex 自带/`hatch-pet` 技能，只要装进 `~/.codex/pets/`，VibePet 自动出现；② 直接把一个宠物文件夹拖进来。
- 不阻塞：用户可"以后再说"，宠物区暂显占位提示。

## 8. 实现期需钉死（spike）
1. inspect 真实 `~/.codex/pets/<slug>/pet.json` 的精确字段名（id/displayName/description/spritesheetPath、是否含网格/帧数/loop/状态行声明），对齐 §2 草案。
2. 多个画廊样本宠物的行序是否一致、`pet.json` 是否声明行映射；确定 canonical 兜底顺序。
3. spritesheet 为 `.webp` 时的解码路径（macOS `ImageIO` 对 WebP 的支持/降级）。
4. 帧切换时 `SpriteHitMask` 重建的开销（可否只用某代表帧或合并 alpha）。

- **Constraint**：纯本地、无网络（本版不做画廊在线安装）；`VibePetCore` 不引入 AppKit/SwiftUI（渲染器 UI 部分在 App，切片/网格/命中在 Core 保持可测）。

- **Decided**：宠物来源 = 共享 `~/.codex/pets/`（原地引用）+ 拖拽导入；**不做自带宠物**（→ 必须有空状态引导，§6.1）。
- **Decided**：老用户**直接丢弃**、无迁移无提示（现无用户）。
- **Decided**：抠图代码**先存档（已完成）后删除**。
- **依赖**：动画行的语义来自子项目 1 的 `SessionState`；子项目 1 未落地前，可先用现有 4 类事件派生临时 `PetVisualState`（idle/review/waving/failed，running 缺省）。
